📦 万物收纳 Pro (本地离线增强版) - 现行功能需求白皮书
《万物收纳 Pro》是一款将“极致数据隐私”与“前沿 AI 视觉技术”完美结合的个人物品管理应用。当前版本彻底剥离了中心化云服务，采用 100% 纯本地运行架构，同时通过开放式 API 接入强大的多模态大模型，彻底解决传统收纳软件“录入繁琐、隐私泄露、容易吃灰”的三大痛点。

🏗️ 1. 核心架构与数据安全 (Local-First)
完全脱离对外部云服务（如 Firebase, 阿里云等）的依赖，确保用户核心资产数据的绝对安全。

纯本地存储引擎 (IndexedDB)：使用浏览器内置的 IndexedDB 数据库，突破了传统 LocalStorage 的 5MB 容量限制，安全、高效地在设备本地存储所有文本和高清图片数据。
断网/飞行模式可用：除了调用 AI 接口时需要网络，软件的核心生命周期（浏览、增删改查、扫码、分类管理）均可在完全无网环境下完美运行。
数据本地备份与恢复：
一键导出：将所有物品明细、经过压缩的图片编码、自定义分类配置打包成标准的 .json 备份文件，下载到用户设备。
无损导入：更换设备或浏览器时，上传 .json 文件即可瞬间恢复所有配置与收纳数据。
🧠 2. 开放式 AI 视觉引擎 (Pro 级核心)
引入强大的自定义大模型接口，支持单件与批量极速入库。

万能 API 接口配置中心：
双引擎兼容：原生支持 Google Gemini 官方格式，以及标准的 OpenAI 兼容格式。
自由切换模型：用户可自定义 Base URL 和 API Key，无缝接入通义千问(Qwen-VL)、智谱(GLM-4V)、GPT-4o、Claude 3.5 Sonnet 等市面所有主流视觉大模型。
智能防呆拦截：内置连通性测试。若用户误填入画图或视频生成模型（如 t2v, i2v），系统会精准拦截并标红警告，防止后续操作报错。
单件智能识别 (AI 看图/语义联想)：
看图填表：拍摄物品照片，AI 自动解析并填充物品名称、分配合适的分类，并生成简短的收纳特征描述。
语义联想：仅输入物品名称，AI 也能推断其所属分类并给出收纳建议。
ListPlus 批量识图入库 (效率神器)：
一图多识：拍摄一张包含多个物品的全家福，AI 自动拆解画面，返回包含“名称、分类、数量”的结构化清单。
微调与批量保存：用户可在弹出的勾选清单中自由修改名称、调整数量。勾选确认后，一键将数十个物品同时存入数据库，并共享该源图片作为视觉参考。
📋 3. 物品全生命周期管理 (CRUD)
提供丰富且实用的字段，覆盖物品管理的方方面面。

多维度属性记录：支持记录名称（必填）、分类、图片、存放位置、数量、到期日、备注信息。
前端图片压缩引擎：用户拍摄或上传的图片，会在存入本地数据库前自动进行 Canvas 尺寸缩放与质量压缩，极大节省设备存储空间，防止数据库因图片过大而崩溃。
原生条码扫码枪 (jsQR)：调用手机前/后置摄像头，全屏扫描商品条形码或二维码，并将解析出的文本自动追加到物品的“备注”字段中。
快捷交互操作：首页卡片支持点击全屏放大查看高清图片；卡片右上角提供快捷编辑与二次确认的删除按钮。
🗂️ 4. 数据检索、分类与可视化看板
数据再多，也能一秒定位。

智能数据看板：
全局物品统计：实时显示当前库内的物品总数。
临期高亮预警：自动监控“到期日”字段，直观展示“30天内即将过期”的物品数量（针对食品、药品、化妆品），并在具体物品卡片上以显眼的橙色高亮提示。
多维检索系统：
全局模糊搜索：支持根据物品名称、存放位置或备注信息进行快速文本匹配。
横向分类标签 (Chips)：顶部提供可滑动的分类栏，点击即可快速筛选特定分类的物品。
分类自定义管理：内置基础分类（衣物、食品等），用户可在“设置”中自由添加个性化分类（如“露营装备”、“乐高”），或删除不需要的分类。
📱 5. PWA 与现代跨平台体验
一套代码，多端完美运行，媲美原生 App 体验。

PWA 桌面/主屏幕安装：支持渐进式 Web 应用标准。用户点击“安装到桌面”即可将网页转化为独立的 App 图标，隐藏浏览器地址栏，沉浸式使用。
响应式 UI 设计 (Tailwind CSS)：界面完美适配竖屏手机、平板电脑和桌面端宽屏，网格布局自动响应调整。
全局 Toast 提示系统：无论是成功保存、网络状态切换还是报错，都有优雅的浮动提示框，提供及时的操作反馈。
网络状态监控：顶部导航栏实时显示当前设备的网络状态（在线/离线），辅助用户判断当前是否可调用 AI 功能。
